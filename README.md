# Cinder

A browser endless runner. Jump, slide, chain a combo, and outrun a line that only gets faster.

Pick a city — Delhi, Lucknow, Mumbai, Hyderabad, Bengaluru, or Chennai — and the road changes: real street names, potholes, oncoming cars and buses, plus famous landmarks and ordinary street corners. Default keeps the foundry line.

- Space or tap to jump, down or swipe to slide
- Speed ramps and denser obstacles over distance
- Ember pickups, close-call combos, and a one-hit shield
- High score saved in the browser

```bash
npm install
npm run dev
```
